# Terraform Practice Repository

This repository contains my personal practice files and labs for learning Terraform.

## About

I use this space to keep track of various scripts and modules I've written while learning and practicing different Terraform concepts, primarily focused on deploying infrastructure in Azure.

## Structure

The folders are generally organized in two ways:
- **By Date:** Many folders are named by the date I worked on them (e.g., `2007`, `3007`).
- **By Topic:** Some folders are named after specific labs (e.g., `terraform-loadbalancer-lab`).

Most of these folders contain basic Terraform configurations for creating foundational Azure resources like Resource Groups, Virtual Networks, Virtual Machines, and more.
